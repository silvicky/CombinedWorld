# CombinedWorld

[English](README.md)

在不同世界之间切换，就像在不同的服务器之间一样。（代理服在面板服上的平替？）

下载见 https://modrinth.com/mod/combinedworld

## 基本概念

这个mod分为core和backrooms两个部分，大部分时候你只需要前者，后者是我们对于一些接口的实现，可以作为参考。

切换世界时物品栏等个人数据会被保存，位置也会被记录。

整个服务器的维度被这样划分：

命名空间 - 内部共享存档数据

世界 - mod的基本单位，一个维度或一组包含主世界、下界和末地的维度，mod会记住你上次的维度和位置。

维度 - 游戏里的一个基本世界

带有原版维度那样后缀的会被视作三个一组的原版世界，否则会被视作独立维度。前者务必确保三个维度同时存在否则传送门会出问题

配置文件：/config/ItemStorage.json 可以选择关闭物品栏存储，或者修改一些参数

存档文件：<save>/data/silvicky/item.dat 大部分都在这

## 命令

不带参数输入命令可以查看具体参数

### 世界切换

```/warp``` 把自己传送到一个世界

```/warptp``` 同上，但可指定被传送的玩家和目标位置

可以用在命令方块里，现在物品栏切换已经注入到游戏底层，所以在指定位置时用原版命令一样效果

```/banwarp``` 设定进入世界需要的权限等级

```/evacuate``` 从一个世界撤离所有玩家到另一个世界，不在线的玩家也可以

```/defaultmode``` 获取或修改命名空间的默认游戏模式

### 玩家管理

```/listdimensionplayers```

```/listworldplayers```

```/listgroupplayers```

列出...的玩家

### 世界管理

```/importworld``` 导入一个原版世界或其主世界（见上）

```/deleteworld``` 删除一个世界

```/createworld``` 从给定世界生成设置创建世界，这可以允许相同的命名空间，因此更加自由

### 世界设置

为后室或者我们服务器的别的什么东西设计，灵感来自咱们[风庄](https://github.com/LS-KR)同学，她在2023.12.24的一次会面中向我介绍了有关内容，并且在之后也给了我很多指导。我不知道我们对非线性空间和卡入卡出的实现是否会让她满意。

对于很多命令，看源代码或许是了解用法的好方法，至少现在如此，因为很多用了二进制编码。

```/silence``` 设置玩家在某个维度不能听到的声音

```/visibility``` 设置玩家在一个维度可见的实体类型，对于其他玩家，有更复杂的选项，例如，让玩家每次死亡后“可见度”变化，只有具有相同可见度的可以看到对方。

```/noclip``` 设置在一个维度开始窒息时卡入另一个世界的概率。

```/noclipvoid``` 设置在一个维度的虚空里卡入另一个世界的概率。每刻都会计算，因此较低的总概率表示掉落更长时间。只要设置了概率，虚空伤害就会被取消。进入另一个世界时的掉落伤害会被取消。

```/darkness``` 强制指定渲染（客户端）和计算（服务端）亮度。

```/distance``` 设置维度渲染和模拟距离。

```/ctrans``` 设置维度区块转换器的类型，也就是客户端访问区块的方式。请确保已将上述距离配置为较小的值，例如4，并在使用这些设置前重启服务器，否则游戏可能会崩溃。此设置是在协议层注入的，因此服务器世界始终有序且静态，而客户端世界则可能因玩家而异。不过，为了保证游戏流畅运行，许多与游戏玩法相关的计算都会进行修改。

"random" 跨越区块边界时重新映射不可见区块。

"linear" 随机平移，防止获得坐标

"xor" 主要调试用

"nop" 原版映射，如果行为与原版有偏差请及时报告

### 其他
